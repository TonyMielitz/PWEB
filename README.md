# PWEB — Programação Web

Repositório destinado às atividades desenvolvidas na disciplina de Programação Web (PWEB) durante minha graduação em Análise e Desenvolvimento de Sistemas na Fatec Sorocaba.

## 📚 Sobre o projeto

Este repositório reúne atividades e exercícios desenvolvidos ao longo da disciplina, com o objetivo de praticar conceitos de desenvolvimento web, estruturação de páginas, estilização com CSS e, no projeto final, desenvolvimento de uma aplicação completa com front-end, back-end e banco de dados, aplicando na prática os conhecimentos apresentados em aula.

## 📂 Atividades

### Atividade 2 — Pesquisa sobre Inteligência Artificial na Educação

Desenvolvimento de uma pesquisa acadêmica sobre o tema Inteligência Artificial na Educação, abordando suas aplicações, benefícios, limitações e desafios no contexto educacional.

### Atividade 3 — Desenvolvimento do site do artigo

Desenvolvimento de uma página web para apresentar o artigo produzido na Atividade 2.

Foram utilizados HTML5 e CSS3 para estruturar e estilizar a página, incluindo menu de navegação, seções de conteúdo, tabelas, listas, citações e outros elementos HTML.

### Atividade 4 — Site de notícias

Desenvolvimento de um site de notícias utilizando HTML e CSS, com aplicação do CSS Grid para estruturar e organizar os elementos da página.

O projeto teve como objetivo praticar a criação de layouts e a organização de diferentes conteúdos em uma página web.

### Projeto Final — Contabilidade Ágil

📁 Pasta: [`ProjetoFinal`](./ProjetoFinal)
🌐 Aplicação publicada: [pweb-production-8fa5.up.railway.app]

Sistema web de controle financeiro, no qual cada usuário cria uma conta, entra no sistema e registra suas receitas e despesas, acompanhando o saldo em tempo real.

O projeto é composto por duas telas:

- **Login / Cadastro:** criação de conta e autenticação do usuário.
- **Painel:** totais de receitas, despesas e saldo, com cadastro, edição e exclusão de lançamentos.

**Tecnologias utilizadas**

- **Front-end:** HTML, CSS e JavaScript
- **Back-end:** Node.js e Express
- **Banco de dados:** SQLite (`better-sqlite3`)
- **Autenticação:** JWT (`jsonwebtoken`) e senhas criptografadas com `bcrypt`
- **Hospedagem:** Railway, com volume para persistência do banco

**Como executar localmente**

Requisito: Node.js 22 ou superior. Dentro da pasta `ProjetoFinal`, execute:

```
npm install
npm start
```

Depois, acesse `http://localhost:3000` no navegador. Mais detalhes, como estrutura de pastas, banco de dados e rotas da API, estão no [README do projeto](./ProjetoFinal/README.md).

## 🎯 Objetivo

Praticar conceitos de desenvolvimento web, organização de projetos e estruturação de páginas, aplicando os conhecimentos adquiridos durante a disciplina por meio das atividades propostas, culminando em uma aplicação completa com front-end, back-end e banco de dados.
